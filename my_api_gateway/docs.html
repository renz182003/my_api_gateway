My API Gateway - Documentation

Available Endpoints:

  • GET /api/users
    Requires header: X-API-Key
    Returns: List of users
    Errors: 401 (Unauthorized), 429 (Rate limit)
  • GET /api/products
    Requires header: X-API-Key
    Returns: List of products
    Errors: 401 (Unauthorized), 429 (Rate limit)
